# 题库与章节内容编辑质量实施计划

对应设计：`docs/superpowers/specs/2026-08-09-question-bank-editorial-quality-design.md`

## 目标

在不修改任何原始 `questions.payload` 的前提下，建立服务端强制的质量覆盖层，完成全量题目审计、章节候选与重复检测、选择题和大题展示修订、55 章知识点深度门槛及结构化来源校验。

## 执行顺序

1. **建立不可变基线**
   - 为本地 3332 道题计算稳定 ID 和原始 payload SHA-256。
   - 增加校验命令，后续所有修订必须证明原始 payload 未变化。

2. **新增数据库质量覆盖层**
   - 创建 `question_quality`、`question_revisions`、`question_quality_events`。
   - 为现有题目补齐默认质量行。
   - 设置 RLS：有效会员只能读取已发布题目和当前修订，普通用户不能写入。
   - 验证无质量行或隐藏题不能通过 REST API 返回。

3. **调整导入、目录和前端数据流**
   - 导入脚本只补齐质量行，不替换原题。
   - 目录数量只统计已发布题；哈希纳入章节、质量状态和当前修订。
   - 前端分页读取质量记录和当前修订，合并后再写 IndexedDB。
   - 保持题目稳定 ID、错题、收藏、随机题和背诵兼容。

4. **实现全量编辑审计工具**
   - 检查题型、答案字母、选项、解析、来源和高风险限定词。
   - 生成章节候选及置信度，不把自动结果标记为人工核验。
   - 检测规范化重复、选项重排重复和语义近重复。
   - 输出不含密钥的本地审计报告和可应用质量清单。

5. **生成非破坏性题目修订**
   - 选择题仅在原解析不足时补充正确项定位、必要的错误项辨析和记忆提示。
   - 大题为全部 203 题生成完整答案展示、得分点、关键词、常见失分和独立解析。
   - 原有充分解析和答案不降级、不覆盖。
   - 所有自动生成内容标记为结构审校，不冒充教材人工核验。

6. **扩充章节知识点**
   - 根据现有教材小节、章节内容和已核验页码，将每章扩充到至少 8 个非重复知识点。
   - 每个新增点包含 3 至 7 条具体内容、关键词、重要等级和来源。
   - 禁止通用模板、伪造页码和长段教材复制。

7. **同步与管理员命令**
   - 默认只报告；`--apply` 才使用 `SUPABASE_SERVICE_ROLE_KEY` 写质量表。
   - 写入前后比较原始 payload 哈希。
   - 记录质量事件并刷新课程目录哈希。

8. **验证**
   - 运行题库审计、编辑质量、章节深度、RLS、懒加载和缓存测试。
   - 运行正式构建和生产安全扫描。
   - 使用浏览器验证有效会员、隐藏题、修订展示、答案初始隐藏和移动端布局。

9. **文档**
   - 更新 README 和 Supabase 部署文档，写明 migration、报告、同步、回滚和验证命令。

## 完成判据

- 原始题目总数和全部 payload 哈希保持不变。
- 3332 道题均能生成质量记录。
- 203 道大题均有可核对得分点和关键词。
- 55 章每章至少 8 个知识点，且来源、ID、内容深度校验通过。
- 低置信度归类和近重复只进入审核队列。
- RLS、会员懒加载、IndexedDB 缓存和生产安全扫描通过。
