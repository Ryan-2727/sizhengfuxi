# 题集导航与解析质量升级设计

## 目标

在不改变 Supabase 鉴权、会员校验、题库懒加载、IndexedDB 缓存和现有刷题功能的前提下：

1. 将左侧“题集”改为带动画的手风琴导航，明确分开选择题和大题。
2. 只修补过短、空泛、重复或与题干不匹配的解析，保留已有高质量内容。
3. 选择题解析达到 2 至 3 句，大题解析提供更完整的定位、得分逻辑和易错点。
4. 解析扩充必须可核验；无法确认的题目进入待核验报告，不生成似是而非的内容。

## 范围与约束

- 不修改题干、选项、标准答案、题型、题目顺序和课程归属。
- 不在浏览器中生成解析，也不把完整题库放回静态部署文件。
- 不改变错题本、收藏、学习进度、随机题、搜索和背诵功能。
- 已有内容只有在解析质量检查不通过时才进入修补范围。
- 完整题库及解析修订仍通过本地忽略目录和 Supabase 管理，不提交到公开仓库或生产静态包。

## 导航交互

### 结构

“题集”保留为一级导航按钮，展开后显示两个二级入口：

- 选择题：显示该课程选择题数量。
- 大题：显示该课程大题数量。

错题本、收藏和需复习继续保留在题集页面顶部筛选栏，不加入左侧导航。

### 行为

- 新进入课程时题集导航默认收起。
- 点击“题集”只切换展开状态，不触发题库重复下载。
- 点击“选择题”或“大题”时，设置现有 `state.type`，滚动至题集区域并保持导航展开。
- 当前题型二级入口高亮。
- 切换章节或重新渲染课程时，只要当前位于题集筛选状态，展开状态继续保持。
- 动画采用约 200ms 的高度、透明度和箭头旋转过渡。
- 在 `prefers-reduced-motion: reduce` 环境中取消动画。

### 可访问性

- “题集”使用真实按钮并设置 `aria-expanded` 与 `aria-controls`。
- 二级容器具有稳定 ID，键盘可正常聚焦两个入口。
- 收起时二级入口不可聚焦，避免隐藏控件进入 Tab 顺序。

## 解析质量模型

### 选择题

只有满足以下任一条件的题目进入修补清单：

- 解析为空或正文不足两句。
- 解析只重复答案字母或题干。
- 含来源文件名、乱码、问号占位或通用无关模板。
- 多选题没有解释各正确项，或解析与答案字母不一致。

合格解析包含：

1. 本题考查的概念、事件、理论或制度。
2. 正确选项成立的依据。
3. 必要时指出干扰项错误类型，并给出简短记忆提示。

单选题通常为 2 至 3 句。多选题须覆盖每个正确选项，并对最有迷惑性的错误项作辨析；不以机械句数代替完整性。

### 大题

标准答案继续保持直接、完整、可用于作答。解析与答案明显分区，解析至少说明：

1. 题目考查范围及题型。
2. 从题干或材料定位知识点的依据。
3. 得分点之间的组织顺序和逻辑。
4. 常见漏点、混淆点或记忆顺序。

大题解析通常为 4 至 8 句；复杂题按得分点分段，不设置机械上限。

## 数据与同步流程

1. 新增只读质量报告脚本，按课程、题型列出短解析、重复模板、答案不一致和待人工核验数量。
2. 修订结果以稳定题目 ID 记录在本地、Git 忽略的解析覆盖数据中。
3. 新增专用同步模式，只更新目标题目的 `payload.analysis` 和必要的审核状态，不改动其余字段。
4. 同步前后校验题干、答案、题型和顺序哈希一致，发现变化立即中止。
5. 同步完成后重新计算 `question_bank_catalog.content_hash`，使对应课程的 IndexedDB 缓存自动失效。
6. 无法用教材、已有核验答案或权威公开材料确认的题目，只写入待核验报告，不进入数据库。

## 页面呈现

- 仍通过现有“显示答案解析”按钮展开答案区。
- 选择题保持“标准答案”和“得分点解析”两个区域。
- 大题保持“完整标准答案”“得分点逐句对照”“常见失分”“解析”四个层次。
- 本次不增加新的装饰卡片、弹窗或复杂动画。

## 错误处理

- 题库尚未加载时，二级导航仍可选择题型；题库加载完成后应用该筛选。
- 若 Supabase 下载失败，沿用现有失败提示和重试按钮。
- 若解析同步发现答案非法、选项缺失或原字段变化，跳过该题并生成明确报告。
- 同步脚本必须使用本地 `SUPABASE_SERVICE_ROLE_KEY`；浏览器和 Cloudflare 环境中不得出现该密钥。

## 验收标准

1. 左侧题集可展开、收起，选择题和大题可独立进入并显示正确题量。
2. 当前题型高亮，页面滚动和筛选正确，题库不会因展开导航重复请求。
3. 桌面端和移动端导航均无重叠；减少动画设置生效。
4. 选择题短解析检查采用句数与内容规则，而不是只检查字符数。
5. 多选题解析与正确选项逐项对应。
6. 大题标准答案与解析保持分离，解析包含定位、得分逻辑和易错点。
7. 同步解析时题干、答案、题型和顺序保持不变。
8. 未核实题目不会获得自动编造的解析。
9. 会员安全、课程懒加载、缓存、错题本、收藏、随机题、搜索和背诵验证继续通过。
10. 正式构建及生产产物扫描不包含完整题库或 `service_role` 密钥。
