# 思政题库可信度修复设计

日期：2026-07-30

## 目标

优先修复现有审计队列中的题目，不以增加题量为目标。正式题库中的题目应当满足题干、选项、题型、答案和解析相互一致，并能够说明核验依据的类型。

## 处理范围

- 近代史：删除 PDF 目录、页码和残缺标题等不可恢复内容。
- 思想道德与法治：恢复 PDF 中被截断的 E/F 选项和答案；涉及法律的题目按现行法律名称、条文和制度更新。
- 毛泽东思想和中国特色社会主义理论体系概论：恢复 E 选项并重新核对答案。
- 习近平新时代中国特色社会主义思想概论：将不带历史时点限定的旧表述更新为现行教材和中央权威文件表述；有明确历史语境的旧表述保留历史限定。
- 马克思主义基本原理：补足与题目直接相关的解析。

## 核验状态

题目使用以下四种状态：

1. `teacher-key-verified`：已与教师原始答案表核对。
2. `textbook-law-verified`：已与教材、现行法律或中央权威文件核对。
3. `authoritative-source-verified`：已与其他权威公开资料核对。
4. `source-backed`：有可追溯来源，但尚未完成独立答案核验。

状态只表示证据等级，不表示低等级题目必然错误。无法通过结构和内容审计的题目仍进入待核验队列，不参与正式题库、题量统计和随机抽题。

## 数据策略

- 原始本地题库文件保留来源内容。
- 已核验的改题、改答案和改解析写入独立修正表，通过规范化题干匹配。
- 修正表可以标记题目永久排除、替换题干、替换答案、替换解析和核验状态。
- 选择题解析器支持 A-F，答案规范化不再丢弃 E/F。

## 自动审计

自动检查以下问题：

- 缺少题干、选项、答案、解析或来源。
- 答案字母不存在、题型与答案数量不一致。
- 选项顺序错乱、E/F 被并入其他选项。
- 题干泄漏答案、目录页码、乱码、模板解析和来源说明混入解析。
- 失效法律名称和无历史限定的旧战略表述。
- 正式题库缺少有效核验状态。

审计报告记录各核验状态数量、待核验原因以及全部待核验题目，便于后续逐题追踪。

## 验收

- 原有 78 道待核验题全部被修复或明确排除。
- 思修和毛概 A-F 题可以正确显示、作答和判分。
- 现行法律题不再引用已经废止的法律名称作为当前依据。
- 习思想题不再把完成全面建成小康社会写成当前未来任务。
- 五门课程各抽检 50 道，重点覆盖多选、否定式、时间、会议、法律和理论概括题。
- `node --check`、题库审计脚本和浏览器交互测试全部通过。
