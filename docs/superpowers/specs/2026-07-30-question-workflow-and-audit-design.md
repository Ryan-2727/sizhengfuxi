# 思政复习站刷题与题库核验设计

日期：2026-07-30

## 目标

本轮改造同时解决两个问题：

1. 增加错题本、收藏和大题背诵功能，让题库能用于持续复习。
2. 将真实性和答案可靠性置于题目数量之前，停止用程序生成的强化变式题补足数量。

完成后，正式题库中的题目必须具备完整题干、有效选项或明确设问、可识别答案，以及与题目直接相关的解析。无法达到要求的题目进入待核验集合，不参与默认题集、首页计数和随机抽题。

## 功能范围

### 选择题练习

- 选择题选项可点击。
- 单选题只能选择一个选项，多选题可以选择多个选项。
- 用户提交后显示正确或错误，并按课程颜色显示结果。
- 答错的题自动加入错题本。
- 用户可主动收藏或取消收藏题目。
- 答案与解析仍默认隐藏，提交后或点击“显示答案解析”才展开。

### 大题背诵

- 大题默认只显示题目。
- “背诵模式”允许逐段显示答案，避免一次展示完整答案。
- 用户可标记“已掌握”或“需复习”。
- 标记为“需复习”的大题进入错题本，收藏状态独立保存。

### 题集筛选

课程题集工具栏提供以下筛选：

- 全部
- 选择题
- 大题
- 错题本
- 收藏
- 需复习

筛选只影响当前课程，搜索可继续与筛选条件叠加使用。

### 本地进度

学习状态使用 `localStorage` 保存，不上传服务器。题目标识使用“课程 ID + 题型 + 规范化题干”的稳定摘要生成，避免题目排序变化导致收藏和错题错位。

保存的数据包括：

- 收藏题目标识
- 错题题目标识
- 大题掌握状态
- 选择题最近一次作答结果

读取失败或旧数据结构不兼容时，网站回退为空状态，不影响题目浏览。

## 题库分层

### 正式题库

正式题库仅包含满足以下条件的题目：

- 题干完整且无答案泄漏。
- 选择题选项能够正确解析，答案字母均对应现有选项。
- 单选和多选标注与答案数量一致。
- 大题答案直接回答设问，不使用“应从几个方面回答”等方法提示代替答案。
- 解析与题干关键词存在明确对应关系，不包含来源说明、乱码或通用占位话术。
- 题目来自用户提供资料、教材配套资料、教师资料或可追溯公开题库。

### 待核验题库

出现以下任一情况时，题目进入待核验集合：

- 程序自动生成或仅通过改变编号形成的强化变式题。
- 缺少答案、选项、题干或必要上下文。
- 答案包含不存在的选项字母。
- 同一题在不同资料中答案冲突且尚未解决。
- 解析与题目无关、只有模板话术或无法支持答案。
- 来源无法识别，且无法通过教材或权威资料复核。

待核验题默认不在页面展示，不计入课程题量，不参与随机抽题。数据可保留在审计产物中，便于后续修正后重新加入。

## 核验流程

### 第一层：结构检查

自动检查：

- 空题干、空答案、空解析
- 选择题选项数量和选项字母
- 答案字母是否存在
- 单选/多选标注一致性
- 答案泄漏
- 重复题和强化变式编号
- 乱码、问号噪声和来源文字混入答案

### 第二层：题意一致性

自动检查题干、正确选项、答案和解析之间的关键词对应。低相关度题目标记为待人工复核，不直接判定为正确。

### 第三层：来源与知识点核对

- 优先使用现行教材、教育部和权威出版机构信息。
- 历史时间、会议、文件、人物和制度表述与教材或权威文献交叉核对。
- 理论概念、基本判断和规范表述以最新版教材和中央权威文献为准。
- 公开题库只能作为题目来源，不能单独作为答案正确性的最终依据。

### 第四层：人工抽检

每门课按题型、章节和来源分层抽样，重点复核：

- 多选题
- 否定式题干
- 时间和会议题
- 相近理论概念
- 答案曾经缺失或冲突的题
- 大题答案较短或解析由程序补充的题

审计报告记录正式题数、待核验题数、失败原因分布和抽检样本。不能证明正确的题不得标记为“已核验”。

## 数据和界面改动

- 题目对象增加稳定标识和核验状态，但来源不在题目卡片中显示。
- 删除运行时补足到 1000 道选择题、200 道大题的循环。
- 删除“强化变式编号”生成逻辑。
- 课程首页和随机题入口使用正式题库的实际数量。
- 题目卡增加收藏、提交、掌握状态等操作按钮。
- 样式沿用五门课程现有配色，不改变首页课程卡布局。

## 验收条件

- 刷新页面后收藏、错题和背诵状态仍存在。
- 单选、多选提交逻辑正确，答错自动进入错题本。
- 大题可以逐段展开并标记掌握状态。
- 筛选和搜索可同时工作。
- 随机抽题不包含待核验题或程序生成变式题。
- 全量自动审计无空答案、无无效选项答案、无答案泄漏、无强化变式、无明显乱码。
- 每门课都生成题库审计统计，所有未通过题目有明确失败原因。
- JavaScript 语法检查、现有站点验证和新增交互验证全部通过。

## 限制

题库规模大，自动检查只能证明结构和一致性，不能替代逐题人工学术审校。项目以“有证据才进入正式题库”为准则，不宣称对开放题库作绝对无误保证；发现冲突时宁可暂时移出题目，也不保留未经证实的答案。
